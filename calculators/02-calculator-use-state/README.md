# Calculator Using useState

## About

A simple React calculator created to practise managing component state with the `useState` hook.

## Features

- Add a number
- Subtract a number
- Multiply by a number
- Divide by a number
- Prevent division by zero
- Clear the input
- Clear the result
- Controlled input using React state

## What I Learned

- How to create and update state with `useState`
- How to create a controlled input
- Input values are stored as strings
- How to convert input into a number before calculating
- How to handle button click events
- How to prevent division by zero
