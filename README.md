# React Playground

A growing collection of small React projects and exercises created while learning and practising React fundamentals.

This repository is my personal learning workspace. Each project focuses on a specific concept, hook, pattern, or problem and is intentionally kept small enough to understand and rebuild from scratch.

## Purpose

- Practise new React concepts
- Build examples without copying complete solutions
- Improve problem-solving and debugging skills
- Compare different implementation approaches
- Record learning progress
- Strengthen JavaScript and React fundamentals

## Topics

Projects in this repository cover:

- React hooks
- State management
- Forms and validation
- Component composition
- Context API
- Custom hooks
- Fetch API and asynchronous JavaScript
- Reusable component patterns
- Performance
- Testing
- Accessibility

## Learning Approach

1. Learn one concept.
2. Build the smallest working example.
3. Rebuild it from memory.
4. Debug mistakes.
5. Document what was learned.
6. Apply the concept in a more complex project.

## Running a Project

Each folder may contain an independent React project.

Navigate to the selected project folder and install its dependencies:

npm install

Start the development server:

npm run dev

## Portfolio Projects

This repository is dedicated to fundamentals, experiments, and micro-projects. Larger and more polished applications are maintained in separate repositories.
