# Login Form (In Progress)

A React login form project created to practice form handling and API communication.

## Current features

✅ Controlled inputs  
✅ Form state management with useState  
✅ Handling input changes dynamically  
✅ Form submission with onSubmit  
✅ Preventing default browser refresh  
✅ Preparing form data object  
✅ Sending POST request with fetch  
✅ JSON.stringify() for API requests  
✅ Async/await with fetch  
✅ Basic error handling with try/catch and response.ok
